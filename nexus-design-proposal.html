概念总览 / Concept Overview

从「聊天窗口」到「认知星云」

过去十年的 AI 界面都是同一个范式：左边一列会话，右边一个聊天框。 这本质上是在模拟微信/iMessage——一个为「人与人即时通讯」设计的交互模式。 但 AI Agent 不是人，它是一个多线程、多模态、持续运作的认知系统。 NEXUS 彻底抛弃聊天窗口范式，用「空间认知场」替代—— 用户的意图是引力中心，Agent 是围绕运转的行星，工具和数据流是星际尘埃。

FIG.01 · NEXUS 空间认知场全景概念图
2020-2025 · 当前范式

💬 聊天窗口模式

  • 左侧会话列表，右侧消息气泡流
  • 线性对话：一问一答，严格排队
  • 单线程：一次只能做一件事
  • 上下文靠 scroll-back 翻历史
  • Agent 是「一个回答问题的盒子」
  • 工具调用隐藏在文字背后，不可见
  • 记忆是黑箱，用户无法感知和操控
  • 多引擎切换 = 新开一个窗口
2025-2035 · NEXUS 范式

🌌 空间认知场模式

  • 无固定布局，意图驱动空间重组
  • 并发认知：多 Agent 同时运转，用户随时介入
  • 多线程：同时追踪多条任务线
  • 上下文是可视化的知识星座
  • Agent 是「围绕用户运转的认知行星」
  • 工具调用是可见的「数据流光线」
  • 记忆是可导航的 3D 星图
  • 多引擎 = 认知场中的不同轨道层
五大设计支柱 / Five Pillars

重新定义 Agent 与人的关系

NEXUS 不是 UI 皮肤翻新，而是对「人机协作」底层范式的重新思考。 五个支柱从不同维度解构了未来 Agent 界面应有的样貌。

01 / SPATIAL

空间隐喻

Agent 不再藏在文字后面，而是以「天体」的形态存在于用户周围。距离 = 关联度，大小 = 重要性，轨道 = 运行周期。空间即信息架构。

02 / CONCURRENT

并发认知

打破「一问一答」的线性枷锁。多个 Agent 可同时处理不同子任务，用户随时拉取任意一条线的进度。像指挥一个团队，而非排队提问。

03 / OBSERVABLE

全程可观测

Plan、Execute、Verify 每一步都是可见的发光节点。数据流像河流一样在 Agent 间流动。用户看到的不是「等待中...」，而是一个活的认知生态。

04 / MEMORY

记忆即地形

长期记忆不再是不可见的数据库，而是可导航的「星座图」。episodic / semantic / procedural 三类记忆以不同颜色的星团呈现，强度映射为亮度。

05 / AMBIENT

环境感知

界面不是独立的「应用窗口」，而是叠加在操作系统上的环境层。Agent 感知当前上下文（当前文件、时间、应用状态），主动提供帮助，而非被动等待输入。

06 / ADAPTIVE

自适应重组

没有固定布局。界面根据用户意图动态重组：写代码时变成 IDE 轨道，做分析时变成数据星图，闲聊时收缩成极简气泡。空间即界面，意图即布局引擎。

五层认知架构 / Cognitive Architecture

从核心到环境层的五重展开

NEXUS 的界面是一个五层嵌套的认知系统——从用户的核心意图球体， 到 Primary Agent 内环、Tool 中环、数据流外环， 最终消融在环境感知层中。

层级 名称 角色 交互方式
L1 · CORE 意图球体 用户当前核心意图的可视化锚点 拖拽改变焦点 / 语音输入 / 快捷键
L2 · INNER Primary Agents 3 个主认知 Agent：感知 / 思考 / 执行 点击展开详情 / 拖拽重排优先级
L3 · MIDDLE Tool Mesh 6 个工具节点：Shell / Web / Memory / File / Code / Cron 双击调用 / 拖拽连接到 Agent
L4 · OUTER Data Stream 实时数据流动可视化，粒子轨迹 = 数据包 悬停查看 / 拖拽截取流片段
L5 · AMBIENT 环境层 系统状态栏 + 弧形输入区 + 全局上下文感知 自然语言 / 手势 / 眼动追踪 (未来)
三种交互范式 / Three Interaction Paradigms

同一空间，三种视角

NEXUS 不是单一视图，而是三种可无缝切换的认知视角。 用户根据场景选择最自然的交互方式—— 看全局用轨道模式，跟流程用流模式，查记忆用星座模式。

轨道模式 · Orbit

默认视图。用户意图居于中心，Agent 以不同轨道环绕运转。 每个节点的颜色代表状态（绿色=活跃，金色=扫描中，蓝色=回忆中，灰色=待命，红色=错误）， 大小代表当前负载。拖拽节点可重新分配优先级。

适用场景：多任务并发、全局监控、团队指挥。

流模式 · Flow

深度执行视图。从 Input → Parse → Plan → Execute → Verify → Output， 每个阶段是一个发光的管道节点，数据粒子在管道中流动。 用户可以随时「掐住」某个阶段，查看中间态，甚至手动注入修正。

适用场景：复杂任务跟踪、Debug、流程审计。

星座模式 · Constellation

记忆导航视图。所有长期记忆以星座图呈现—— 金色 = episodic（事件记忆），蓝色 = semantic（知识记忆），绿色 = procedural（技能记忆）。 节点大小映射召回强度，星座连线映射记忆间的关联。 可缩放、搜索、手动连接/断开记忆节点。

适用场景：记忆管理、知识图谱探索、上下文回顾。

演进路线 / Evolution Roadmap

从今天到 2035

NEXUS 不是一步到位的幻想，而是一条可落地的渐进路径。 每个阶段都在现有基础上叠加一层认知能力，最终收敛为完整的空间认知场。

PHASE 01 · 2025 Q3-Q4
v1.0 · 轨道视图 Prototype
在现有 KinetAios 的 Electron 框架内，用 Canvas/SVG 实现轨道视图。 Agent 节点绑定现有引擎（Direct / Claude Code / Codex）， 点击展开当前对话流。保留传统聊天气泡作为 fallback 模式。 布局从 sidebar+chat 切换为 radial+overlay。
PHASE 02 · 2026
v2.0 · 并发认知 + 流模式
TaskManager 支持多线程并发任务，每个任务在轨道上独立运转。 引入 Flow 视图，Plan/Execute/Verify 全链路可视化。 数据流粒子用 Web Animation API 实现高性能流动效果。 弧形输入区替代底部文本框。
PHASE 03 · 2027-2028
v3.0 · 记忆星座 + 3D 空间
长期记忆系统升级为可导航的 3D 星座图。 引入 Three.js / WebGPU 渲染层，轨道视图从 2D SVG 升级为 3D 空间。 用户可在 3D 空间中飞行穿梭，查看 Agent 内部状态和记忆关联。 支持 VR/AR 设备的沉浸式认知场体验。
PHASE 04 · 2029-2032
v4.0 · 环境感知 + 多模态融合
NEXUS 不再是独立应用，而是操作系统级的认知叠加层。 Agent 感知全局上下文：当前窗口、文件、剪贴板、摄像头、麦克风。 支持眼动追踪交互、手势控制、脑机接口预研。 语音交互从 ASR/TTS 升级为实时语音流认知。
PHASE 05 · 2033-2035
v5.0 · 完全空间认知场
界面与物理空间融合——AR 眼镜上的全息认知场。 Agent 以空间中的光点、声场、触觉反馈存在。 用户通过自然语言 + 手势 + 眼动 + 思维意图直接操控认知场。 「界面」概念消融，取而代之的是「认知共生」。
