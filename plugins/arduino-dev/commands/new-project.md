你现在要帮用户创建一个新项目。请按以下步骤操作:

## 1. 确认项目信息

向用户确认(已有信息不用再问):
- 目标芯片/开发板(如 ESP32、ESP32-S3、Arduino Uno)
- 项目功能描述(如"温湿度传感器 + OLED 显示 + WiFi 上传")
- 项目名称

## 2. 查看环境

使用 `board_list` 查看已安装的开发板核心。如果用户目标板型未安装,用 `lib_install` 安装。

## 3. 搜索需要的库

根据功能需求用 `lib_search` 搜索需要的库,确认库名后用 `lib_install` 安装。

## 4. 生成项目代码

创建项目目录和 `.ino` 文件,包含:
- 文件头注释(项目名、功能、硬件配置、接线说明)
- 引脚定义区(统一管理所有 GPIO)
- 库引入区
- 全局变量区
- `setup()` —— 串口初始化、传感器初始化、网络连接
- `loop()` —— 主逻辑框架(留 TODO 注释)
- 必要的辅助函数

## 5. 接线说明

用表格或 ASCII 图呈现引脚连接方案:
```
传感器引脚  →  开发板引脚
VCC         →  3.3V
GND         →  GND
SDA         →  GPIO 21
SCL         →  GPIO 22
```

## 6. 编译验证

使用 `arduino_compile` 编译生成的代码。如果编译失败,分析错误并修正,直到编译通过。

最终给出项目结构概览和下一步建议。
