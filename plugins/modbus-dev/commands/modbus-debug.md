name: modbus-debug
description: Modbus 一站式调试 —— 扫描设备 + 读寄存器 + 写寄存器 + CRC 校验
---

用户需要对 Modbus 设备进行全面调试。按顺序引导:

1. **扫描设备**: 调用 `modbus_scan` 找到在线从站
2. **读寄存器**: 用 `modbus_read` 读取目标寄存器(默认功能码 0x03 保持寄存器)
3. **CRC 校验**: 如果用户有原始帧数据,用 `modbus_crc` 验证或计算 CRC
4. **写操作**: 确认无误后,用 `modbus_write` 写入(写前会要求用户确认)

提示用户安全注意事项:
- 写操作可能改变工业设备状态(如变频器频率、阀门开度)
- 建议先读后写,确认寄存器映射正确
