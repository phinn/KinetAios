**发布日期：** 2026-07-12

KinetAios 首个正式版本——Windows 11 平台的三引擎 AI Agent 面板。

### 核心特性
- **三引擎架构** — Kaios(内置 ReAct)/ Claude Code / Codex,每会话可切换
- **9 个内置工具** — shell / read_file / write_file / edit_file / grep / glob / web_fetch / recall_memory / git_diff
- **SQLite + FTS5** — 对话历史全文检索 + 长期记忆抽取
- **全局热键** 快速呼出 Quick Panel;**MCP 协议** stdio transport 接入外部 Server
- **成本追踪** — 实时 token 消耗 + 费用统计
- **Files / Git / Rules 内联 Tab**;Workbench 项目视图(按 cwd 分组)
- **Dashboard 窗口**、长期记忆面板(查看/编辑/删除)、暗/淡色主题
- **四语言 i18n**(en / zh-CN / zh-TW / ja)、@文件引用、插件与 Agent 自动扫描

---

**English**

First stable release — a three-engine AI agent dashboard for Windows 11.
- **Three engines**: Kaios (built-in ReAct) / Claude Code / Codex, switchable per conversation
- **9 built-in tools** (shell / files / grep / web_fetch / memory / git_diff); **SQLite + FTS5** history search and long-term memory
- Global hotkey quick panel; MCP (stdio) support; real-time token & cost tracking
- Inline Files / Git / Rules tabs; Workbench project view; Dashboard window; memory panel
- Dark / light themes; **i18n in 4 languages** (en / zh-CN / zh-TW / ja); @file references; plugin & agent auto-discovery
