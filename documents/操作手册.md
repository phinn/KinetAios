# KinetAios 操作手册

> **版本**: v2.3.0 | **平台**: Windows 11 / macOS | **协议**: GPL v3

KinetAios 是本地优先（Local-First）的多引擎 AI Agent 工作台。一个窗口同时运行 DirectV2 / Claude Code / Codex 三个引擎，支持跨引擎长期记忆、27 个领域插件、MCP 多机协作、实时语音对话。无需账号，无需中继服务器——你的 API Key 就是唯一凭证。

## 1. 安装与首次配置

### 安装

- **Windows**: 从 [GitHub Releases](https://github.com/phinn/KinetAios/releases) 下载 `KinetAios Setup x.x.x.exe`，双击安装。
- **macOS**: 下载 `.dmg`，拖入 Applications。
- 安装包未签名 → Windows SmartScreen / macOS Gatekeeper 会警告，选择「仍然运行」即可。

### 首次启动配置

1. 启动后进入**设置页面**（齿轮图标 ⚙️）。
2. 填入核心配置：

| 配置项 | 说明 | 示例 |
|---|---|---|
| **API Key** | LLM 服务商的 API 密钥 | 智谱 GLM / DeepSeek / OpenAI 等 |
| **Base URL** | API 端点地址 | `https://open.bigmodel.cn/api/paas/v4` |
| **Model** | 模型名称 | `glm-5.2` / `deepseek-chat` / `gpt-4o` |
| **API Protocol** | 协议类型 | `openai`（大多数）/ `anthropic`（Claude 原生） |

3. 默认预置了**智谱 GLM** 配置，填入 API Key 即可用。
4. 也可以选其他预置（DeepSeek / OpenAI / Anthropic / Ollama 本地模型等）。

### 使用 Claude Code / Codex 引擎（可选）

1. 先在本机安装对应 CLI：
   - Claude Code: `npm install -g @anthropic-ai/claude-code`
   - Codex: `npm install -g @openai/codex`
2. 在设置中打开「启用 CLI 引擎」开关。
3. 安装后引擎选择器里就会出现对应选项。

## 3. 会话管理

### 新建会话

- 点击侧边栏 **➕** 按钮，或 `Ctrl+Alt+Space` 打开快速面板后新建。
- 每个会话独立配置：引擎、模型、工作目录。

### 会话操作

| 操作 | 方式 |
|---|---|
| **切换会话** | 侧边栏点击对应会话 |
| **重命名** | 双击会话标题 |
| **删除** | 右键 → 删除 |
| **清空当前对话** | 输入框空时无法直接清空，删除会话重建即可 |

### 多会话并发

- 可以同时运行多个会话，每个会话独立流式输出。
- 后台会话的 AI 回复不会丢失，切回来时完整呈现。

### 工作目录（CWD）

- 每个会话可设置独立的工作目录（默认用户主目录）。
- 点击引擎栏的目录路径可修改。
- 工作目录影响 shell 命令的执行路径和文件操作的根目录。

## 4. 三大引擎

KinetAios 支持在同一会话内切换引擎（切换会清除当前引擎的上下文）：

### Direct（内置 ReAct 引擎）

- **无需外部 CLI**，直接调用 LLM API。
- 内置 ReAct 循环：思考 → 调用工具 → 观察结果 → 继续思考。
- 支持 Plan-Execute-Verify-Judge 四层自审架构（DirectV2）。
- **唯一使用内置工具的引擎**（shell / read_file / write_file / web_fetch / recall_memory 等）。

### DirectV2（增强版 Direct）

- 在 Direct 基础上增加：
  - **自动上下文压缩**：超过预算时自动摘要早期对话。
  - **四层自审**：Plan → Execute → Verify → Judge。
  - **文件快照自动回滚**：每次文件修改前自动创建快照。
- 适合长对话和复杂任务。

### Claude Code

- 通过 `claude -p --output-format stream-json` 调用本地 Claude Code CLI。
- 使用 `--resume` + session id 恢复上下文。
- 支持注入记忆（`--append-system-prompt`）。
- **不使用内置工具**（有自己的工具链）。

### Codex

- 通过 `codex exec --json` 调用本地 Codex CLI。
- 支持 JSONL 流式输出和会话恢复。
- **不使用内置工具**。

### 引擎对比

| 特性 | Direct | DirectV2 | Claude Code | Codex |
|---|---|---|---|---|
| 需要外部 CLI | ❌ | ❌ | ✅ | ✅ |
| 内置工具 | ✅ | ✅ | ❌ | ❌ |
| 长期记忆 | ✅ | ✅ | ✅ | ✅ |
| 上下文压缩 | 手动 | 自动 | CLI 管理 | CLI 管理 |
| 文件快照 | ✅ | ✅（自动） | ❌ | ❌ |
| 推理深度控制 | reasoning 参数 | reasoning 参数 | CLI 参数 | CLI 参数 |

## 5. 内置工具

Direct / DirectV2 引擎可调用以下工具（AI 自主决定何时使用）：

### 核心工具

| 工具 | 功能 | 说明 |
|---|---|---|
| **shell** | 执行 Shell 命令 | Windows 走 cmd.exe，macOS 走 /bin/sh |
| **read_file** | 读取文件 | 支持按行范围读取大文件 |
| **write_file** | 写入文件 | 覆盖写入，无大小限制 |
| **edit_file** | 编辑文件 | 精确匹配替换，支持 replace_all |
| **grep** | 搜索文件内容 | 正则搜索，自动排除 node_modules/.git 等 |
| **glob** | 列出文件 | 按 glob 模式匹配 |
| **web_search** | 网络搜索 | 返回标题/摘要/链接 |
| **web_fetch** | 抓取网页 | 返回干净的 Markdown/纯文本 |
| **recall_memory** | 搜索历史记忆 | 语义搜索长期记忆和历史对话 |

### 高级工具

| 工具 | 功能 |
|---|---|
| **dispatch_agent** | 派发子任务给独立子 Agent（只读，并行探索） |
| **remember_fact** | 保存会话级锚点（跨步骤共享关键数据） |
| **recall_fact** | 读取之前保存的锚点 |
| **spawn_team** | 创建 Agent 团队（多角色并行协作） |
| **team_broadcast** | 给团队所有成员广播指令 |
| **team_send** | 单独给某个团队成员发指令 |
| **team_close** | 删除团队 |
| **memory_replace** | 更新核心记忆块（user_profile / project_context / active_goals） |
| **memory_append** | 向记忆块追加内容 |

### 工具确认（Shell Confirm）

- 当 `approval` 设为 `always` 时，AI 执行 shell 命令前会弹窗请求确认。
- 弹窗显示完整命令，你可以允许或拒绝。
- 设为 `never` 则跳过确认（适合信任场景）。

## 6. 文件与代码操作

### 文件浏览器

- 点击底部「文件」标签打开文件浏览器。
- 功能：
  - **浏览目录树**：基于当前工作目录。
  - **预览文件**：支持文本、图片、HTML（WebView 预览）。
  - **编辑文件**：内置简易编辑器。
  - **Markdown 渲染**：.md 文件自动渲染预览。

### 文件快照与回滚

- DirectV2 引擎在修改文件前**自动创建快照**。
- 点击底部「更多」→「快照」查看历史快照。
- 可以选择某个快照**回滚**到之前的文件状态。

## 8. 长期记忆系统

KinetAios 拥有三层记忆系统：

### 第一层：核心记忆块（Memory Blocks）

- **结构化常驻记忆**，每轮自动注入到 AI 上下文。
- 三个块：

| 记忆块 | 内容 |
|---|---|
| **user_profile** | 用户画像（技术栈、偏好、工作习惯） |
| **project_context** | 当前项目上下文（架构、约定、进展） |
| **active_goals** | 当前目标 |

- AI 会自动更新这些块（使用 `memory_replace` / `memory_append`）。

### 第二层：长期记忆（自动提取）

- 系统每轮对话后**自动提取**关于用户的持久事实。
- 存储在 SQLite + FTS5 全文索引中。
- 下次对话时自动注入相关记忆。
- 用 `recall_memory` 工具可语义搜索全部历史。

### 第三层：会话摘要（Episodic）

- 每次会话结束自动生成摘要。
- 下次打开可以看到「最近做了什么」。
- 摘要包含关键决策、修改的文件、执行的操作。

### 记忆图谱

- 点击底部「记忆」标签，查看可视化的记忆图谱（SVG）。
- 展示记忆节点之间的关联关系。
- 支持搜索和浏览单条记忆。

### 替身画像（Persona）

- 从历史对话中提取用户的做事风格（Markdown 文本）。
- 开启后，AI 会**模仿用户的风格**自主执行任务。
- 在设置中可以编辑或重新生成画像。

- **设置 → 插件**：查看所有已安装插件。

- 插件提供的能力：

| 能力 | 说明 |
|---|---|

### Slash 命令

- 在输入框开头输入 `/` 打开命令菜单。
- 显示所有可用的插件命令。
- 支持分类筛选和关键词搜索。
- `↑↓` 选择，`Enter` / `Tab` 确认，`Esc` 关闭。

## 10. 语音对话

### 实时语音助手（豆包实时语音）

基于火山引擎实时语音大模型，WebSocket 双向音频流。

**配置**：

1. 设置 → 语音对话 → 填入：
   - **App ID**：火山引擎应用 ID
   - **Access Token**：访问令牌
   - **Voice Type**：音色 ID（如 `zh_female_wanwanxiaohe_moon_bigtts`）
2. 开启「启用语音入口」。

**使用**：

- 点击输入框旁的 🎤 麦克风按钮开始语音对话。
- 说话时实时转写，AI 实时语音回复。
- 对话过程中 AI 可以同时执行工具调用（如读文件、搜索）。
- 支持上下文感知（注入当前项目名和最近对话摘要）。

### 语音输入（Web Speech API）

- 设置中开启 `voiceAutoSend` 后，语音按钮切换到实时模式。
- 说话时实时显示文字，VAD 检测静音后自动发送。

## 11. MCP 多机协作

KinetAios 同时是 MCP **客户端**和**服务端**。

### 本机 MCP Server（作为工具节点）

- **设置 → MCP → 本机 Server**：
  - 开启后，本机变为 MCP Server，局域网内其他 KinetAios 实例可连接。
  - 配置端口号（默认 18109）和鉴权 Token。
  - 暴露的能力：shell / read_file / write_file / web_fetch 等所有内置工具。

### 远程 MCP Server（连接其他节点）

- **设置 → MCP → 远程 Server**：
  - 添加远程 KinetAios 节点的 URL 和 Token。
  - 连接后，AI 可以调用远程机器的工具。
  - 适合多台电脑协作场景（如 Mac 调用 Windows 的硬件工具）。

## 12. Pipeline 跨引擎编排

### 什么是 Pipeline

Pipeline 允许你**串联多个引擎**完成复杂任务：

```
Stage 1 (DirectV2)  → 分析需求、生成方案
Stage 2 (Claude Code) → 写代码实现
Stage 3 (Codex)      → 审查和优化
```

### 使用方式

1. 创建 Pipeline 模板：每个 Stage 指定引擎 + Prompt。
2. 运行 Pipeline：按顺序执行每个 Stage，结果传递给下一个。
3. 模板可保存和复用。

## 13. Agent 团队（Team）

### 概念

创建多个独立 AI Agent 成员，各自有不同角色，并行处理任务：

- 每个 member 是独立的 sub-agent，有各自的持久化对话历史。
- 可以同时持有团队上下文。
- 适合并行调研、多视角评审、分模块探查。

### 操作方式

AI 会自动创建和管理团队：

1. **spawn_team**：创建团队，定义成员角色。
2. **team_broadcast**：广播统一指令，各成员独立处理。
3. **team_send**：单独追问某个成员。
4. **team_close**：任务完成后解散团队。

## 14. 全局搜索与快速面板

### 全局对话搜索

- **快捷键**：`Ctrl+Shift+F`（macOS: `Cmd+Shift+F`）
- 跨所有会话搜索历史对话（基于 FTS5 全文索引）。
- 支持中英文模糊搜索。

### 快速面板（Quick Panel）

- **快捷键**：`Ctrl+Alt+Space`（macOS: `Cmd+Alt+Space`）
- 任何时候悬浮弹出一个迷你对话框。
- 可以快速提问、新建会话、查看回复。
- 不打断当前工作流。

## 15. 设置详解

### 基本设置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| **API Key** | LLM 服务商密钥 | — |
| **Base URL** | API 端点 | 智谱 GLM 地址 |
| **Model** | 模型名称 | `glm-5.2` |
| **API Protocol** | 协议（openai / anthropic） | `openai` |
| **Reasoning** | 推理深度（none/minimal/low/medium/high/xhigh/max） | `none` |
| **Language** | 界面语言（中文/English/日本語/繁體中文） | `zh-CN` |
| **Theme** | 主题（8 种：dark/light/aurora/serene/tahoe/sierra/craft/seed） | `dark` |

### 安全设置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| **Approval** | Shell 命令确认策略（always 每次确认 / never 从不确认） | `always` |
| **Sandbox** | 沙箱模式（限制文件访问范围） | `workspaceWrite` |
| **Plan Mode** | 计划模式（AI 只规划不执行） | 关 |

### 模型配置档（Model Profiles）

- 保存多套完整的 LLM 配置（API Key + Base URL + Model + Protocol + 价格）。
- 每个会话可快速切换不同的配置档。
- 适合同时使用多个 LLM 服务商。

### 成本与预算

| 设置项 | 说明 |
|---|---|
| **Price In/Out per 1M tokens** | 输入/输出价格（用于成本计算） |
| **Budget** | 预算限制（单次会话 / 每日上限），超出自动熔断 |
| **Max Turns** | Direct 引擎单轮最大 ReAct 循环数（防死循环，默认 50） |

### 上下文管理

| 设置项 | 说明 | 默认值 |
|---|---|---|
| **V2 Model Window** | 模型上下文窗口大小 | 1,000,000（GLM-5.2） |
| **V2 Budget Ratio** | V2 预算比例（占窗口百分比） | 8% |
| **HiFi Context Budget** | 高保真模式上下文预算 | 200,000 |

### Embedding 接口

- 独立于主 LLM 接口的 Embedding 配置。
- 留空 = 跟随主接口。
- 用于长期记忆的向量检索。
- Ollama 用户自动切换为 `nomic-embed-text`。

### 窗口行为

| 设置项 | 说明 | 默认值 |
|---|---|---|
| **Close Behavior** | 关窗行为：quit 退出 / minimize 最小化 / tray 托盘 | `minimize` |

### 数据存储位置

| 平台 | 路径 |
|---|---|
| **Windows** | `%APPDATA%\KinetAios\` |
| **macOS** | `~/Library/Application Support/KinetAios/` |

包含：`settings.json`（配置）、`history.db`（SQLite 对话历史 + 长期记忆）、`voice-debug.log`（语音调试日志）。

### 命令行构建

```bash
npm install          # 安装依赖 + 编译 better-sqlite3
npm run build        # 编译主进程 + 打包渲染进程
npm run typecheck    # 类型检查（主要验证步骤）
npm start            # 启动应用（需先 build）
npm run dev          # build + start
npm run dist         # 打包 Windows NSIS 安装包
npm run dist:mac     # 打包 macOS DMG
```
