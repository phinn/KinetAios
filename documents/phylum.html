提案 V2 修订 · 2026-10-13 · KinetAios DirectV5(directV5 / phylum-engine 插件) · 状态:化石层已落地(1165999),真实模型批跑待验

01主张与一句话设计

核心主张:Agent 不学习,Agent 繁衍。 重复性任务流上,Phylum 种群的边际 token 成本随化石沉积趋近于零—— LLM 不是种群的居民,是种群的燃料:烧一次,把轨迹烧成化石;此后同类任务直接重放化石,零 LLM 交付。 裸 ReAct 每次都重新烧一遍,成本是常数;Phylum 的成本是递减序列。

EN. Agents don't learn — they breed. On recurring task streams, Phylum's marginal token cost decays toward zero as successful traces fossilize into replayable templates. The LLM is the population's fuel, not its resident: burn once, deposit a fossil, replay forever after at zero LLM tokens. A bare ReAct agent re-burns every time — flat cost. Phylum's cost is a decreasing series.
预注册边界(防事后挑数据):Phylum 优势定义域 = 重复性任务流(同类签名反复出现)。 一次性任务没有种群意义,等价于裸模型,Phylum 不承诺任何优势。签名命中率即定义域判据。

02基因与选择:三件套

基因位内容进化方式表达机制
routing_priormaxSteps / 颗粒度 / 成功先验定向突变(死因驱动)硬约束:步数墙物理截断
tool_affinity数值向量,每工具一维罚肇事(−0.30/步)、奖缺位(+0.3)、扰动硬约束:亲和 <0.2 从注册表物理摘除,不是提示词劝说
assertion_templates断言 DSL(exit_code_eq / output_not_empty / line_count_gt…)只删不改不进化(防 Goodhart)硬约束:post-condition gate,违规即死

LLM 行为约束必须上机制(断供/熔断/摘除),提示词只配当辅助——这是立法引擎(V4)三连败换来的教训。

EN. Three gene loci: routing priors, per-tool affinity vector, assertion templates. All expressed as hard constraints (tools physically removed from the registry below 0.2 affinity; assertion gate kills on violation), never as prompt suggestions. Assertions are delete-only — they never evolve, to block Goodharting.

03死亡归因决定突变位点

每个个体的死因被结构化归因,子代在死因位点定向突变(疤痕遗传),不做盲目随机搜索:

死因归因字段子代突变

EN. Structured death attribution drives targeted mutation at the culprit locus — no blind random search. Abortions leave no trace: zero ledger, gamete, fossil, or attribution.

04成本曲线:为什么"归零"要靠重放而不是编译

坑①(程序综合)先摆在这:轨迹 → 程序的编译比一句话难一个数量级。 轨迹里的参数不是常量——路径、URL、query 都是任务实例的函数;谁来填槽? 编译器必须同时解决参数实例化、环境漂移、语义等价性三个问题,而这三件事恰好是 LLM 最不可靠的地方。 所以主路径不是编译:是轨迹模板(槽位化)+ 断言 gate 的重放。真编译挂远期(见 06 节档③)。

成本曲线的正确读法是期望 + 方差,不是单点确定性曲线:

图 4-1 · 累计 token 曲线(期望示意)。Phylum 前期学费 ≈ 3× ReAct(种群并行的进化学费), 归因与沉积节奏有随机性(带状区间=方差);化石接管后边际斜率≈0。此曲线形态由 harness 双曲线(08 节)验证,不预设数值。

账本口径同步修正——账本记的是统计量,不是确定性流水:

账本字段(档②口径)含义方差处理
trials / successes支系尝试/成功计数(含重放命中)精确计数,无方差
costZSum类内归一化成本 z 分累计期望 ~3× 学费期,带方差;跨签名不可比(类内归一)
重放命中率(近窗)化石接单占比归因可能误判(tool_error 不总是工具的错)→ 退役/摘除线留冗余,不做单点阈值迷信
EN. Pit #1 (program synthesis) comes first: compiling traces into programs is an order of magnitude harder than it sounds — trace parameters are functions of the task instance (who fills the slots?), environments drift, and semantic equivalence is exactly where LLMs are least reliable. So the main path to zero is slot-based trace templates + assertion-gated replay, not compilation. Cost curves must be read as expectation + variance: tuition phase ≈3× ReAct with attribution noise; slope ≈0 once fossils take over.

06三档退场:种群终态的去 LLM 化

种群不能永远烧燃料。收敛后的支系按三档退场,档②就足以兑现"归零"主张,档③直接做是最贵路径:

档机制边际成本工程风险状态
① 冻结路由支系近窗达标(trials≥6 且成功率≥0.8)→ 本能 prompt:"路线已验证,沿用"~30%(省 70%)低 —— 只省推理长度,仍走 LLM✅ 已落地 isConverged
② 轨迹重放成功轨迹沉积为槽位化化石模板;同类任务先重放(参数槽+断言 gate),命中=零 LLM;未命中降级开荒~0%中 —— 槽位抽取与漂移管理(Voyager 已验证同类技能库路径)✅ 已落地 replay.ts
③ 真程序编译轨迹 → 确定性程序(参数实例化相关)~0%(同②)高 —— 坑①全套:参数/漂移/等价性;收益与②重叠🕐 远期,不承诺时间表
为什么②是主路径:归零主张的分母是"同类任务再跑一次的 token"。 ②用「上次的轨迹 + 这次填槽」直接交付,LLM 完全不在场,断言 gate 兜底正确性; ③多买不到任何东西(同样 ~0%),却要先解决程序综合的全部难题。先②后③是成本最优序,不是妥协。
EN. Three-tier exit so converged lineages stop burning fuel. Tier 1: frozen routing (instinct prompt, ~30% cost). Tier 2: trace replay — slot-filled fossils, assertion-gated, zero LLM on hit, auto-degrade on miss (the main path; Voyager validated the skill-library pattern). Tier 3: true program synthesis — high risk, zero extra benefit over Tier 2, explicitly deferred. Tier 2 alone delivers the zero-claim.

07坑②:化石腐化闭环(重放不是终局,是带保质期的合约)

化石不是资产,是带保质期的负债:环境一漂移,重放就在正确性上撒谎。 所以重放必须闭环——gate 不过就当场降级,并把"化石病"作为归因信号反哺基因库:

图 7-1 · 化石腐化闭环:重放命中交付为零 token;败=gate 拦截(用户永远看不到坏产物)→ 降级 LLM 开荒 → 连续 2 次 miss 化石退役(环境漂移防护)→「化石病」归因反哺基因库 → 新成功轨迹重新沉积。 化石会死,种群不会。

设计要点:

  • gate 在交付之前:重放的每一步过断言 DSL,坏产物到不了用户手里——这是重放敢接单的前提;
  • 退役线留冗余:FOSSIL_MISS_RETIRE=2,归因可能误判,不做单点阈值迷信(呼应坑③);
  • 口碑继承:同签名换化石时继承旧化石的重放战绩,漂移历史不清零;
  • 已落地:replay.ts(extractSlots 槽位抽取 + replay 零 LLM 重放)、registry.noteReplay(hit/miss 记账+退役)、templates.json 持久化。
EN. Pit #2 (fossil rot): fossils are liabilities with a shelf life — environment drift makes replays lie about correctness. The loop: replay → assertion gate → pass = deliver at zero tokens; fail = gate blocks (user never sees a bad artifact) → degrade to LLM pioneering → 2 consecutive misses retire the fossil; "fossil disease" feeds back into the gene library as attribution, and fresh successful traces re-compete for deposit. Fossils die so the population doesn't.

08验证:harness 双曲线

验收标准不是"成功率曲线"单指标,而是成功率曲线 + 累计 token 曲线两条一起看: 成功率证明种群能活并收敛,token 曲线证明收敛后真的省——只有前者,档②接进去也无法证明主张。

EN. Acceptance = twin curves from the harness: success-rate (selection pressure works; already shaped in mock) + cumulative tokens (tuition ≈3× ReAct with variance, slope ≈0 after fossils take over — the direct evidence for the zero-claim, including the crossover point). Minimal prototype scope: template store + parameter slots + assertion gate + fallback attribution. No program synthesis.
