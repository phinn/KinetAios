三个颠覆之前结论的发现

发现 1:Reddit / HN / awesome 清单的引荐数为 0。Referrers 实测:github.com 内部 76、自己官网 phinn.github.io 34、Bing 13、YouTube 2、Google 1——没有一条来自 reddit.com、news.ycombinator.com 或任何清单站。v2 报告里"+2 星归因 weekly thread"是错的:那条评论没有带来任何可测流量。真实来源是 GitHub 站内(topics/搜索/explore)和 Bing 搜索。
发现 2:转化率高得反常,问题 100% 在量不在质。14 天 56 个独立访客 → 8 星 ≈ 14%(近期 +2 星来自约 10 个 uniques,≈20%)。行业均值 1-3%。意味着只要把日独立访客做到 50-100,按现转化率月增 150-300 星。产品门面(desc/homepage/GIF/README)已经能打,不需要再打磨转化,全部精力应该投向引流。
发现 3:Clone 数据 95% 是机器人,以后不要参考。8/6 当天 views uniques=5 人、clone uniques 却有 80「人」——5 个访客不可能产生 80 个克隆者。这是 GitHub 生态的已知现象(安全扫描器/爬虫批量 clone 小仓库)。clones 1159 总量看似漂亮,作流量信号已废,判断热度只看 views uniques。
