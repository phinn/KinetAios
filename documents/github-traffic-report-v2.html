核心洞察

48 小时 +2 星(6→8)是 5 周来第一次外部驱动增长。期间仓库零 push 推广、零发帖,唯一变化是 weekly thread 评论 + 仓库门面修缮(desc/homepage/GIF/banner 清理)。虽然样本极小,但验证了之前的诊断:不是产品问题,是分发问题——门面修好后,少量精准流量也能转化。
转化漏斗初步成形:曝光→repo visit→star。8/15-16 两天 star +2,而前 5 周平均周增速 <1。推算 weekly thread 精准曝光 ~100-200 次 → 2 star ≈ 1-2% 转化,符合"精准小流量"预期。要在 30 天内到 100 星,按此转化率需 ~5000-10000 精准曝光——只有 Show HN 上首页 / LocalLLaMA 高赞帖 / awesome 合并三件事能达到这个量级。
三个高杠杆渠道全部押在未来 2-4 周:Show HN 复活(养号 + 本人重写文案)、LocalLLaMA 攒 karma、PR #1397 合并。当前唯一"活着"的 weekly thread 每周贡献 ≈2 星。增长曲线的下一个拐点完全取决于这三件事的执行,而不是再加码目录站。
代码产出与星数严重脱节:37 天 734 commits、19 个 tag、48 个 TS 文件 3.6 万行,却只有 8 星。这是典型的"build in dark"。开发节奏(几乎每日 push)不必降,但推广节奏必须从"月度脉冲"改为"周度脉冲"——每周至少一个外部曝光事件(评论/答题主战场贴/渠道动作),和 commit 一样排进日程。
