KinetAios 隐私政策

生效日期:2026-09-07 · 本政策适用于 KinetAios(macOS / Windows 桌面应用)。

一句话版本

KinetAios 是本地优先(Local-First)应用:你的所有数据都只存在你自己的电脑里,我们没有任何服务器,不收集、不上传、不追踪。

1. 我们收集什么

什么都不收集。应用不内嵌任何账号系统、统计 SDK、崩溃上报或广告组件;不存在开发者侧的数据服务器。

2. 数据存在哪里

API Key操作系统钥匙串(macOS Keychain / Windows DPAPI),仅本机
对话与记忆本机 SQLite 数据库(应用沙盒容器内),仅本机
遥测数据无
上传从不(除下述第 3 条)

3. 唯一的数据出设备场景

当你使用 AI 对话功能时,应用会把当前会话上下文发送到你自己在设置中配置的第三方大模型服务商 API 地址(如 OpenAI、Anthropic、智谱、本地 ollama 等)。该传输由你发起、指向你指定的服务,受该服务商隐私政策约束;KinetAios 本身不中转、不存储、不查看这些请求。不配置任何 API Key 时,应用不会发出任何网络请求(语音、MCP、更新检查等联网功能同理,均需你主动启用并填写你自己提供的地址)。

4. 权限使用

  • 麦克风:仅当你主动开启语音对话时采集音频做实时识别,不在后台录音。
  • 屏幕截图:仅当你调用截图工具时使用,需系统授权。
  • 文件访问:仅访问你通过系统面板授权的目录,以及应用自身的数据目录。

5. 儿童

应用不面向 14 岁以下儿童收集任何信息(事实上我们不收集任何人的信息)。

6. 政策变更

若未来引入任何数据收集,将在此页面显著更新并提高版本号。
