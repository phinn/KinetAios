## 5. Stop conditions

- views 涨但 star 不涨 → 停分发,回头改 README 首屏/定位
- star 涨但 release 下载不涨 → 改 demo/安装引导
- Reddit 帖被删 → 不绕版规重发,冷却(现状:09-27 已停,等 10-22)
- Show HN 平淡 → 不制造互动,素材改投 dev.to 复用
- 任何渠道 3 次动作 0 点击 → 该渠道降级为周更
