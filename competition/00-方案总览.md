# 参赛方案总览

## 方案名称

**KinetAios × AgentTeams：本地优先的增强型多智能体协同分析平台**

——以自研开源 Agent 引擎 KinetAios 作为 AgentTeams 的增强 Worker 节点，构建企业级设备运维数据分析场景的多 Agent 团队

## 核心叙事

> AgentTeams 提供了优秀的 Manager-Worker 编排基座，但标准 Worker（OpenClaw/QwenPaw）只有基础工具调用能力。
>
> **我们用自研开源 Agent 引擎 KinetAios 替代标准 Worker，通过 MCP 协议将 12 个内置工具 + 18 个办公插件能力注入 AgentTeams 生态**，使每个 Worker 节点从"只能调 API 的薄壳"升级为"拥有文件系统、代码执行、数据分析、可视化生成能力的自主 Agent"。

## 一句话定位

**AgentTeams 管调度，KinetAios 管干活。**
