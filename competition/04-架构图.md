## 2. 任务协同流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant M as Manager
    participant MQ as RocketMQ
    participant W1 as Worker-数据工程师
    participant W2 as Worker-分析师
    participant W3 as Worker-报告员
    participant FS as MinIO/共享文件
    
    U->>M: "分析 Q3 停机率，找出异常经销商"
    M->>M: 复述确认 + 拆解为 4 子任务
    
    M->>MQ: 发布 task-fragment: 数据清洗
    MQ->>W1: 消费子任务
    W1->>FS: 读取 Q3_raw_data.xlsx
    W1->>W1: KinetAios ReAct: 清洗+标准化
    W1->>FS: 写入 Q3_cleaned.csv
    W1->>MQ: 发布 task-complete
    MQ->>M: 通知完成
    
    M->>M: 验收 Q3_cleaned.csv ✓
    
    M->>MQ: 发布 task-fragment: 统计分析
    MQ->>W2: 消费子任务
    W2->>FS: 读取 Q3_cleaned.csv
    W2->>W2: KinetAios ReAct: Pandas 聚合+3σ检测
    W2->>FS: 写入 analysis_result.md
    W2->>MQ: 发布 task-complete
    MQ->>M: 通知完成
    
    M->>M: 验收分析结论 ✓
    
    M->>MQ: 发布 task-fragment: 报告生成
    MQ->>W3: 消费子任务
    W3->>FS: 读取 analysis_result.md
    W3->>W3: KinetAios: ECharts 暗色主题
    W3->>FS: 写入 Q3_报告.html
    W3->>MQ: 发布 task-complete
    MQ->>M: 通知完成
    
    M->>M: 验收报告 ✓
    M->>U: 推送报告 + 摘要
```
