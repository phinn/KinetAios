# 作品简介

## 项目名称

**KinetAios × AgentTeams：本地优先的增强型多智能体协同分析平台**

## 项目概述

本方案以阿里云开源多智能体协同框架 **AgentTeams** 为编排基座，以自研开源 Agent 引擎 **KinetAios**（GPL v3，GitHub: phinn/KinetAios）为增强 Worker 节点，构建面向企业设备运维数据分析的多 Agent 协同平台。

**解决的核心问题**：AgentTeams 的标准 Worker（OpenClaw/QwenPaw）仅具备基础 LLM 调用能力，无法直接操作文件系统、执行代码、处理 Excel/CSV 数据或生成可视化报告。我们的方案让每个 Worker 节点通过 MCP 协议获得 KinetAios 的 12 个内置工具（shell/文件读写/搜索/Web 抓取/子 Agent 派发）和 18 个办公插件工具（Excel 读写/PDF 生成/OCR/CSV 分析），实现从"只会聊天"到"能干实事"的质变。

## 技术方案

**架构分两层**：Manager Agent 负责需求解析、任务拆分、Worker 调度、结果验证（AgentTeams 原生能力）；Worker 节点由 KinetAios MCP Server 提供，拥有完整 ReAct 推理循环和工具链，可自主完成数据分析任务。

**Agent 角色**：Manager（任务编排）、数据工程师（Excel/CSV 清洗）、分析师（停机率统计+异常检测）、报告员（ECharts 可视化+HTML 报告生成）。

**七项推荐技术映射**：Higress 作为 AI 网关统一模型路由与 MCP 托管；Nacos 管理 Agent 配置与 Skills 注册发现；PolarDB-PG 存储设备数据+pgvector 向量记忆；RocketMQ 驱动异步任务分发与状态流转；云 Skills 门户按需加载领域技能；AgentScope Studio 记录 Agent 推理轨迹用于质量评估；UnifiedModel 统一建模设备/经销商/工单实体关系。

**安全边界**：KinetAios 三级沙箱（readOnly/workspaceWrite/fullAccess）+ SSRF 防护 + 文件写入自动快照回滚 + AgentTeams 零凭证架构（Worker 永不接触 API Key），双重保障。

## 开源价值

KinetAios 已在 GitHub 开源（GPL v3），提供完整的 MCP Server 实现参考。方案中 KinetAios 作为 AgentTeams 生态的增强 Worker 范例，可被任何 AgentTeams 用户直接复用——将 MCP Server 地址配入 Worker 的 MCP Server 绑定即可获得增强能力。我们计划将场景 Skills 和 Worker 模板贡献回社区，降低企业数据分析 Agent 团队的搭建门槛。
