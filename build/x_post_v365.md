## 回帖素材（thread 用）

1/ Why local-first? Because "AI coding assistant" shouldn't mean "upload my codebase to someone's server". KinetAios keeps the model API key usage but the code, history, memory — all SQLite on your disk.

2/ The overnight goal mode is the killer feature: give it a goal, a supervisor agent validates each round's output, and when your Coding Plan's 5h window runs dry it switches to the next model in your failover chain automatically. Wake up to finished work.

3/ Computer Use on macOS is sneaky-good: the agent clicks and types via background event injection — you keep working while it works. Screenshots can even hide the app window first.
